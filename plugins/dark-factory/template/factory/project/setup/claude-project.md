# Set up the claude.ai Project

> Skeleton. `factory-kickoff` replaces every `TODO` with this project's values and rewrites the prose in `project.language`. No secrets in this file.

## Why a Project

- It keeps the planning context in one place: research, decisions, diagrams and domain rules live there as files and instructions, so every chat and task in it starts with that context instead of someone pasting it again.
- Tickets stay short: they point to the exact doc instead of copying it, and the runner tasks created inside the Project can read it.
- `ticket-quality` used inside it searches that research to fill a ticket's Context.
