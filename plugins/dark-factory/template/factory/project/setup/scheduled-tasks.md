## Prompt

Every task uses the same prompt; only the job changes:

```
Project repo: TODO (branch TODO)
Clone the repo and run the job defined in factory/jobs/<job>.md. Follow that file exactly.
```

## Create them

`factory-kickoff` creates the tasks itself when the session can, runs each one once to test it, and marks **Created** ✅. What it cannot set from a session is left ⏳ for a person:

1. Choose the model in each task's settings (status O7).
2. Turn on automatic approval for the board checks (they only read).
3. If the project uses a claude.ai Project: move the two runners into it if they were created outside it (status R6).

To create one by hand: new scheduled task with the name and prompt above, the cron in the table, the connectors, then run it once and check the result.

## When something changes

| When this changes… | Do this |
|---|---|
| A threshold, the team or the velocity | Edit `factory/project/config.md`. Tasks read it on their next run. |
| Sprint length, start day or daily time | Run the kickoff: it recomputes the schedule, updates the tasks and this file. |
| The project ends | Pause the tasks. |
